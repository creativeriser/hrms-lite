# HRMS Lite

A lightweight Human Resource Management System (HRMS) built with the MERN stack (MongoDB, Express.js, React.js, Node.js).

## Features
- Employee Management (CRUD)
- Attendance Tracking
- Professional Dashboard UI

## Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** Vite, Mongoose

## Setup Instructions

### Backend
1. Navigate to `backend/`
2. `npm install`
3. Create `.env` file (see `.env.example`)
4. `npm run dev`

### Frontend
1. Navigate to `frontend/`
2. `npm install`
3. `npm run dev`
